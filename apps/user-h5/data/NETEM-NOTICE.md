# NETEMVocabulary 数据说明

当前 `words.js` 使用 [exam-data/NETEMVocabulary](https://github.com/exam-data/NETEMVocabulary) 的 `netem_full_list.json`，去重后包含 5528 条词条。

- 数据版本：v7.1，基于 2024 年考研英语（一）大纲
- 数据许可证：CC BY-NC-SA 4.0
- 代码许可证：MIT（本项目没有重新发布其代码）
- 本项目当前仅用于非商业 Demo 和内部验证，不应直接用于商业发布
- 音标、词性和演示图片词的多义项由 [ECDICT](https://github.com/skywind3000/ECDICT) 数据补充/提取，遵循其 MIT 许可证；原有 Demo 图片和谐音内容继续保留

后续切换可商用词库时，需要替换 `apps/user-h5/data/words.js` 和本说明，不应混用未授权的释义、例句、音频或图片。
