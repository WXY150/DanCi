## 4. 必测用例

### 学习规则

- 新词第一次选择“我已经认识”：进度增加 1，进入下一个词。
- 新词选择“想不起来”：立即显示答案，进度不增加。
- 进入答案后选择“记住了”：进度仍不增加，词进入后续队列。
- 该词第二次、第三次连续选择“记住了”：第三次才增加进度。
- 三次记忆过程中任何一次选择“还不会”：连续次数清零，词继续复现。
- 本轮存在不会词时，队列不会在普通词结束后提前结束。
- 点击“再学一轮”：直接显示新一轮第一个词，上一轮统计归零。

### 数据与异常

- 学习中刷新、返回、关闭后重新进入：队列、当前词、连续次数保持。
- localStorage/云接口不可用：给出提示或降级，不阻断当前学习。
- 图片或音频加载失败：文字学习仍可继续。
- 快速重复点击答案按钮：同一张卡片不能被重复计数。
- 今日无到期复习词：展示空状态，不显示无效开始按钮。

## 5. 后续接口预留

当前服务边界继续保持以下契约，后续只替换实现：

- `contentProvider.listTodayWords()`：今日词、词书、词库版本和素材地址。
- `progressStore.load/save/clear()`：用户进度、会话恢复和云端同步。
- `audioService.play(word)`：发音播放和后续真人音频资源。
- `feedbackService.submit(state, wordId, value)`：反馈上报和后续埋点。

后续可新增但本周不实现的接口：

- `authService`：匿名态、微信登录和账号绑定。
- `reviewService`：复习日历、间隔算法和补学任务。
- `analyticsService`：开始、完成、退出、复现和反馈事件。
- `contentAdminService`：词条审核、素材替换和词书发布。

## 6. 进度管理规则

- 每个任务必须有负责人、产出物和验收条件，不能只写“开发中”。
- 每天结束更新一次本表：状态只使用“未开始、进行中、已完成、阻塞、后置”。
- 出现新增需求时先标记为“候选”，说明是否影响 D+7 交付，再决定是否进入本周。
- P0 问题优先于视觉微调；商业化、社交和复杂 AI 能力不得挤占 P0 工期。
